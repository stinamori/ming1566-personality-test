# 大明人格 · 1566 MVP

React + Vite + TypeScript + Tailwind CSS + React Router；Node API 与 UI 分离。

## 本地启动

需要 Node.js 20.19+（推荐22）。

```sh
npm ci
npm run dev
```

打开 http://localhost:5173 。Vite 自动代理 `/api/score` 至本地3001端口。这就是开发模拟评分服务，前端始终通过可替换 `ScoringService` 接口调用HTTP，不导入角色参数。

```sh
npm test
npm run build
npm start
```

生产方式本地预览：http://localhost:3001 。`PORT` 可覆盖端口。`npm start` 同时服务构建产物和评分API。Vite preview 仅提供静态资源，不提供评分API。

## Vercel 部署（推荐）

将本目录作为独立仓库/项目根目录导入Vercel，选择Vite，安装 `npm ci`，构建 `npm run build`，输出 `dist`。`api/score.ts` 自动成为Node函数；`vercel.json` 支持SPA深链接。不要仅上传dist到纯静态托管后期待评分正常。发布后验证 `/quiz` 刷新、完成40题、API返回version 4.1.0、PNG保存及二维码域名。

## 腾讯云 CloudBase 部署

最直接方式：将整个项目作为Node容器部署到CloudBase云托管，构建运行下面Dockerfile，容器端口3001，开启HTTPS。前后端同源，无需CORS。镜像中包含服务端评分数据，浏览器无法访问该目录。

未来迁移云函数时，在HTTP触发函数中调用 `server/engine.ts` 的 `evaluate(event.answers)`，使用和 `server/handler.ts` 相同的输入校验及错误格式。前端设置 `VITE_SCORE_API` 为HTTP函数HTTPS地址再构建；跨域时后端须限定允许的网站Origin并处理OPTIONS。函数包装层需要按所选CloudBase运行时适配事件格式。

## 文件结构与边界

- `src/questions.json`：由原题库提取的题干和原始量表；40题原文不变，不下发评分映射。
- `server/data/questions.v4.json`：原始完整题库。
- `server/data/characters.v4.json`：原始V4.1参数，仅服务端读取。
- `server/data/characters.v4.2.candidate.json`：原样留存供开发比较，不接入生产路径，不提供前端切换入口。
- `server/data/scoring.cjs`：保留原算法，仅纠正返回版本元数据；原型14维及特征计算、排序、隐藏款判定均不变。
- `server/engine.ts`：评分服务边界、严格校验及最小响应；不返回用户画像或角色权重。
- `src/service.ts`：可替换评分服务接口，HTTP错误可重试。
- `public/assets/characters`：原有22张PNG，严世蕃文件名已统一。
- `src/share.ts`：Canvas生成900×1440 PNG；二维码指向当前网站首页，不含答案。

注意：原代码注释称Q38和Q40都至少4，但实际算法采用F6平均值≥4；本项目按要求保留实际算法，不擅自调整。隐藏世子以独立彩蛋展示，不取代常规TOP3。角色title作为核心人格标签，description作为解读，均来自原始资料。

## 隐私、兼容与验证

答题进度存于当前设备localStorage；评分时仅提交40题答案，不收集姓名。服务端不记录答案。存储被浏览器禁用时展示提示。结果刷新后从本地答案重新计算。无登录、无埋点。相似度为模型内匹配分数，不是经验证的科学概率。

六档圆形选项在桌面和手机端横向排布；选项下方采用椭圆翻题按钮，适配安全区。首页22位人物支持自动轮播、左右按钮和触摸横向滑动，悬停/聚焦暂停，并尊重系统减少动态效果设置。PNG在微信内长按保存，其他浏览器可下载。分享二维码需网站可公开访问，localhost二维码只适用于开发。微信真实设备中的图片长按行为仍应在上线前验收。

基础测试覆盖数据/头像完整性、输入边界、106组评分回归、反向计分、隐藏条件边界。请勿把服务端源码目录作为静态目录发布。Vercel/CloudBase部署需要你的账号配置，本交付不含已上线站点。

## UI更新（2026-10-27）

整体采用朱红、暖金、宣纸色。标题使用Ma Shan Zheng书法字体，正文使用Noto Serif SC；字体子集随项目本地托管，许可证见public/fonts。新增文案时如缺少字符，会回退至系统中文字体；可重新生成字体子集。人物原图继续使用原始22张素材。

轮播当前为每2.4秒切换，中央人物置顶，前后人物在两侧缩小露出；支持触摸滑动及键盘方向键。答题六档统一浅黄色外圈，选中为纯红色实心圆（不显示数字或对勾），仅0分/5分显示端点标签。

## 再次打开与重新开始

首页按本机有效答案数量显示：未作答「开始测试」、未完成「继续测试」、40题完成「查看结果」。有答案时提供「重新开始」，确认后清空当前进度并返回第一题；取消保留原答案。评分版本仍为V4.1。首页隐藏人物以问号卡片展示，真实头像仅在解锁结果中出现。轮播底部控制栏已移除，保留自动播放、滑动和键盘方向键。

## 结果解读与单屏手机布局

`src/characterInsights.ts` 存放22位人物的展示文案（四个标签、优势、相处方式、温和提醒），不参与评分或修改人物参数。部分较尖锐的展示称谓改为中性表达；分享海报同步使用展示称谓。头像采用独立网格布局与contain缩放，避免覆盖解读。

手机端按440×956及更矮的可用视口检查：首页、答题和结果单屏布局；结果用五个分类标签切换内容，桌面端显示完整解读。页面未用overflow:hidden强行裁掉文字，系统放大字体或极小视口时允许自然扩展。原始设备规格参考https://support.apple.com/en-asia/148591 ，440×956为本项目模拟的CSS视口；真实微信/Safari工具栏和安全区仍随设备环境变化。
